ESPACE ADMINISTRATEUR

Le poste de commande.

Cette page est actuellement un écran de préparation. Les commandes du site sont envoyées directement à WhatsApp. Aucun historique partagé ni connexion administrateur sécurisée n’est encore configuré.

Prochaine étape : connecter Supabase

  • Créer un projet Supabase et récupérer son URL et sa clé publique anon/publishable.
  • Créer les tables de commandes et activer Row Level Security (RLS).
  • Créer le compte administrateur dans Supabase Auth et lui attribuer le rôle admin côté serveur.
  • Ajouter une Edge Function pour valider et enregistrer les commandes sans exposer de clé secrète.
  • Charger les commandes dans ce tableau de bord après connexion admin.

Sécurité : ne place jamais une clé service_role, un mot de passe ou un secret dans les fichiers publics de GitHub Pages.
